# Don Queso - Sitio Web Oficial

Sitio web moderno y elegante para Don Queso, empresa especializada en la venta de quesos, cecinas y alimentos congelados en Talca, Chile.

## 🚀 Características

- **Diseño Moderno**: Interfaz tipo ecommerce premium con colores relacionados a comida
- **Responsive**: Compatibilidad total con dispositivos móviles
- **Animaciones Suaves**: Efectos con Framer Motion
- **Integración WhatsApp**: Pedidos rápidos por WhatsApp
- **SEO Optimizado**: Optimización local para Talca, Chile
- **Carga Rápida**: Lazy loading de imágenes y optimización

## 🛠️ Tecnologías

- **React 18** - Framework de UI
- **TypeScript** - Tipado estático
- **Vite** - Build tool
- **TailwindCSS** - Estilos
- **Framer Motion** - Animaciones
- **React Icons** - Iconos
- **React Scroll** - Smooth scrolling

## 📦 Instalación

1. Clonar el repositorio
2. Instalar dependencias:
```bash
npm install
```

3. Iniciar el servidor de desarrollo:
```bash
npm run dev
```
